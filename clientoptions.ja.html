クライアントオプション


プレイヤーの「クライアント・オプション」は、彼らが世界中にできることに影響を与えます。 例えば、プレイヤーの設定でダブルジャンプができます。 airJumpCount to 1. また、自分の健康バーが設定することで増加することができます maxHealth to 200. これらのAPIメソッドは、クライアントoptionsを変更することができます: 
/**
 * クライアントのオプションをランタイムで変更し、変更した場合にクライアントに送信する
 *
 * @param {PlayerId} playerId
 * @param {PassedOption} option - The name of the option
 * @param {ClientOptions[PassedOption]} value - The new value of the option
 * @returns {void}
 */
setClientOption(playerId, option, value)

/**
 * クライアントオプションの現在の値を返します
 *
 * @param {PlayerId} playerId
 * @param {PassedOption} option
 * @returns {ClientOptions[PassedOption]}
 */
getClientOption(playerId, option)

/**
 *ランタイムでクライアントオプションを変更
 *
 * @param {PlayerId} playerId
 * @param {Partial<ClientOptions>} optionsObj - An object which contains key value pairs of new settings. E.g {canChange: true, speedMultiplier: false}
 * @returns {void}
 */
setClientOptions(playerId, optionsObj)

/**
 * クライアントオプションをデフォルト値に設定します。 これは、あなたのゲームのdefaultClientOptionsに保存されている値になります, それ以外の場合は、Bloxdのデフォルト.
 *
 * @param {PlayerId} playerId
 * @param {ClientOption} option
 * @returns {void}
 */
setClientOptionToDefault(playerId, option)

利用可能なクライアントのoptionsの完全なリストは次のとおりです。

airAccScale


Typeの: number
Defaultの: 1
エアボーン選手に応募する加速量。
Rocket Obby が 0.25 を使用した場合のみ変更します。
プレイヤーは、既定のブロックスの動きの動作と速度に使用されます。
異なる筋肉のメモリが必要な場合は、ゲームから離れる場合があります。
api.applyEffectを使用して、速度や低速効果を適用することをお勧めします。

airFrictionScale


Typeの: number
Defaultの: 1
エアボーン選手に適応する摩擦量。
絶対に必要な場合はのみ変更します。 i.e. Rocket Obby は 0 を使用します。
プレイヤーは、既定のブロックスの動きの動作と速度に使用されます。
異なる筋肉のメモリが必要な場合は、ゲームから離れる場合があります。
api.applyEffectを使用して、速度や低速効果を適用することをお勧めします。

airJumpCount


Typeの: number
Defaultの: 0
空気の量はプレーヤーに持っています跳びます

airMomentumConservation


Typeの: boolean
Defaultの: false
プレイヤーが空気中を襲い、運動量を節約できるようにするかどうか。
Rocket Obby のみが真を使用する必要がある場合にのみ変更します。
プレイヤーは、既定のブロックスの動きの動作と速度に使用されます。
異なる筋肉のメモリが必要な場合は、ゲームから離れる場合があります。
api.applyEffectを使用して、速度や低速効果を適用することをお勧めします。

ambientLightColourOverride


Typeの: string
Defaultの: null
包囲された(空の光のabsence)色の上書き - hexの文字列例えば #ffffffff.

arrowPotionEffectDuration


Typeの: number
Defaultの: 6000
矢印のポチオン効果の持続期間

auraPerLevel


Typeの: number
Defaultの: 100
Aura XPは、レベルごとにいくら必要です。

autoRespawn


Typeの: boolean
Defaultの: false
True なら、secsToRespawn 秒後に自動的にプレイヤーが再発します

ログイン


Typeの: number
Defaultの: 0
プレイヤーが固形ブロックをバウンスする頻度
1 の値は、マッシュルームとして機能する全てのブロックと同等です。

bunnyhopMaxMultiplier


Typeの: number
Defaultの: 1.3
バニーホーピング時にジャンプ高さの最大乗数

cameraPositionOffset


Typeの: [number, number, number]
Defaultの: [0, 0, 0]
[x, y, z] 世界単位で3人目のカメラをオフセット

cameraRoll


Typeの: number
Defaultの: 0
放射状のカメラのロール角度。 過渡効果、死の効果、等のために有用な。

cameraRollTransitionMs


Typeの: number
Defaultの: 0
カメラロール角度(cameraRoll変更時)にアニメーション/トランスレーションにmsの期間。 0 = インスタント。
スムーズなカメラロールの移行に役立ちます。

cameraRotationOffset


Typeの: [number, number, number]
Defaultの: [0, 0, 0]
[x, y, z] の3人目のカメラを回転させます。

cameraTint


Typeの: [number, number, number, number]
Defaultの: null
RGBA 配列 [r, g, b, a] カメラ画面の色合い効果. 0と1の間の値が落ちます。

canAltAction


Typeの: boolean
Defaultの: true
プレイヤーがaltアクションキーを使うかどうか(PCの右クリック)

canChange


Typeの: boolean
Defaultの: true
プレイヤーがブロックを変更できるかどうか

canClimbWalls


Typeの: boolean
Defaultの: false
プレイヤーが壁を登ることができるかどうか

canCraft


Typeの: boolean
Defaultの: true
プレイヤーがアイテムを作成できるようにするかどうか
useFullInventoryはこれのために働くために本当でなければなりません

canCrouch


Typeの: boolean
Defaultの: true
プレイヤーがワクワクできるかどうか

canCustomiseChar


Typeの: boolean
Defaultの: true
プレイヤーが自分のキャラクターをカスタマイズできるかどうか

canFish


Typeの: boolean
Defaultの: true
プレイヤーがデフォルトで魚を釣れるかどうか
Bloxdで釣りゲームプレイ。 あなたが望むなら、このを無効にすることができます
カスタム(非QTE)釣りメカニックスを書く

canPickBlocks


Typeの: boolean
Defaultの: true
プレーヤーがブロックを選ぶことができるかどうか(ミドルマウスはPCの上でクリック)、クリエイティブが偽の場合無視

canPickUpItems


Typeの: boolean
Defaultの: true
プレイヤーがアイテムをピックアップできるようにするかどうか

canSeeNametagsThroughWalls


Typeの: boolean
Defaultの: true
プレイヤーが壁を通して名前札を見ることができますか

プレイヤーがブロックを破る失敗したときにエラーメッセージ

プレイヤーは、既定のブロックスの動きの動作と速度に使用されます。
異なる筋肉のメモリが必要な場合は、ゲームから離れる場合があります。

プレーヤーが脚や頭を打つときのMult。 銃のみに適用されます

Typeの: number
Defaultの: 8000
ひび割れたココナッツからの+速度の効果の持続期間

ezBridging


Typeの: boolean
Defaultの: true
ブリッジ支援時に、プレイヤーはブロックの端からブロックを置くことができます。
目指すことなく立ち向かうが、そのブロックは場所で成長し、固形になる
終了時 - それまで置くことはできません。

ブロックは900msで仕上げられ、アシストブリッジング1.11ブロック/s:クロウよりも遅くなります。
速度のブリッジングと速度が遅くなるので、スキルの天井が保存されます。 成長する
セルは決して有効なサポートであり、助けはそれを見るのではなく1つで止まります、従って
1つの目的に沿ってブリッジアウトすると、一度に1つのブロックをペースアップします。 クリエイティブではブロックが
ペースがないため、即座に配置されます。 ezBridgingGrowMs 成長時間を変更します。

ezBridgingGrowMs


Typeの: number
Defaultの: null
どのくらいの長さで、ミリ秒全体(0〜60000)で、ezブリッジングブロックは、それがなる前に成長する
固体。 0 は即座に配置します。 設定した時にもクリエイティブにも適用されます。 default: 900ms または
創造的瞬間。

fallDamage


Typeの: boolean
Defaultの: false
落下時にプレイヤーにダメージを与えるかどうか

flySpeedMultiplier


Typeの: number

クリエイティブモードで飛行速度のためのマルチプライヤー

fogChunkDistanceOverride


Typeの: number
Defaultの: null
グラフィック設定を上書きする霧距離。 null の場合、グラフィック設定を使用します。

fogColourOverride


Typeの: string
Defaultの: null
フォグカラーオーバーライド用のRGB文字列。 例: #ffffffff

fogOnSkybox


Typeの: boolean
Defaultの: false
空箱に霧をつけ、そうでなければ霧によって影響されない。

forcedCameraDirection


Typeの: [number, number, number]
Defaultの: null
カメラを強制して、特定の方向[x, y, z]を参照してください。 無料のカメラの動きを可能にするためにnullに設定します。

forcedCameraDirectionTransitionMs


Typeの: number
Defaultの: 0
余計な ms で animate/transition へ強制的なカメラの方向 (forcedCameraDirection を変更した場合). 0 = インスタント。
スムーズなカメラの動きに役立ちます。

gravityMultiplier


Typeの: number
Defaultの: 1
通常の動きの間に重力に適用される多層。
デフォルトの重力のために1に設定します。

groundArrowPath


Typeの: { target: [number, number, number]; colour?: string; }
Defaultの: null
このプレーヤーからターゲット位置まで地面にアニメーションチェブロン矢印の地形追従ストリップをレンダリングします。
矢印パスは他のプレイヤーには表示されません。
ターゲットポジションの設定 target: [x, y, z] 非表示にするには、または null を表示してください。
オプション colour CSSカラー文字列(例: "red", "#ffa00", "rgb(255,0,0)")、またはデフォルト白のnullです。

groundFrictionScale


Typeの: number
Defaultの: 1
グラウンドプレイヤーに適用される摩擦量。
絶対に必要な場合はのみ変更します。 i.e. Rocket Obby 使用 3.
プレイヤーは、既定のブロックスの動きの動作と速度に使用されます。
異なる筋肉のメモリが必要な場合は、ゲームから離れる場合があります。
api.applyEffectを使用して、速度や低速効果を適用することをお勧めします。

gunshotOrigin


Typeの: GunshotOrigin
Defaultの: "default"
ガンショットが発祥する場所。
-"default" は、古典的な空白の挙動を保存します(3人目のカメラから発祥のキャスト)。
-「頭」は常にプレーヤーの頭からレイキャストをスポーン。 特定のカメラの視点に立たせる

headerChips


Typeの: HeaderChip[]
