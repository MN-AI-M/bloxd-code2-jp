クイックタイムイベント(QTEs)


QTEsは、応答(クリック、保持など)を必要とするプレーヤーに表示されるインタラクティブなプロンプトです。 サーバ側のゲームコードからトリガーされます。 api.addQTE() 結果は、 onPlayerFinishQTE コールバック。

プロフィール


  • progressBar: 急激にクリックして進捗バーを埋める。
  • timedClick: タイムウィンドウ内でクリックして成功します。
  • gravityBar: クリックして、移動対象と一致するキャッチゾーンを保持します。
  • precisionBar: マーカーが成功ゾーン内にあるときにクリックして成功します。
  • rhythmClick: 外側の円が固定された内側の円と整列するときにクリックします。

progressBar


プレイヤーは繰り返しクリックし、進行バーを増加させます。 棒は絶えず時間に排水します。 100%に到達すると、QTEが正常に完了します。 お問い合わせ canFail 真実であり、進捗は 0 に達し、QTE は失敗します。 それ以外の進行は 0 でクランプされ、プレーヤーは試行を続けることができます。

パラメーター


type ProgressBarQteParams = {
    progressStartValue?: number // 進行値(0-100)を開始します。 default: 30の特長
    progressDecreasePerTick: number // プレイヤーがクリックされていない間、プレイヤーが各ティックを排出する量はどのくらいかかります。 default: 0.075 の
    progressPerClick: number // クリックごとにどれだけの進捗が得られるか。 default:5の
    canFail: boolean // True なら、進捗が 0 に達すると QTE が失敗します。 それ以外の場合は 0 で進捗クランプを処理します。 default:偽り
    description: CustomTextStyling // QTEのプロンプトとして示されている豊富なテキスト。 default: [{ str: クリックして繰り返し完了!]
    clickIcon: string // クリックターゲットにアイコンが表示されます。 default:「ファソリッドファコンマウス」
    scale?: number // クリックアイコンのマルチプライヤーをスケール(最大> 0)。 default: 1の特長
    rotation?: number // クリックアイコンの度に回転(≥ 0 である)。 default: 15の特長
}

Sensible デフォルト


api.addQTE(playerId, {
    type: "progressBar",
    parameters: {
        progressStartValue: 30,
        progressDecreasePerTick: 0.075,
        progressPerClick: 5,
        canFail: false,
        description: [{ str: "Click repeatedly to complete!" }],
        clickIcon: "fa-solid fa-computer-mouse",
        scale: 1,
        rotation: 15,
    },
})

timedClick


プロンプトが表示され、タイマーが実行される前にプレーヤーがクリックする必要があります。 タイムウィンドウ内でクリックすると、QTEが失敗します。

パラメーター


type TimedClickQteParams = {
    timeWindow: number // プレイヤーがクリックしなければならないミリ秒の期間。 default:3000の
    icon: string // クリックターゲットにアイコンが表示されます。 default:「ファソリッドファコンマウス」
    label: CustomTextStyling // QTEのプロンプトとして示されている豊富なテキスト。 default: [{ str: "QTEを完了するためにクリックしてください!"
    showTimer: boolean // カウントダウンタイマーを表示するかどうか。 default:真
    scale?: number // アイコンのマルチプライヤー(must be > 0)をスケールします。 default: 1の特長
    rotation?: number // アイコンの度に回転(≥0である)。 default: 15の特長
    breatheCenter?: boolean // 真の場合、アイコンは中央に固定された呼吸アニメーションでパルスします。 default:偽り
}

Sensible デフォルト


api.addQTE(playerId, {
    type: "timedClick",
    parameters: {
        timeWindow: 3000,
        icon: "fa-solid fa-computer-mouse",
        label: [{ str: "Click to complete the QTE!" }],
        showTimer: true,
        scale: 1,
        rotation: 15,
        breatheCenter: false,
    },
})

gravityBar


移動体はバーに沿って移動し、定期的に方向を変えます。 プレイヤーはクリックして、キャッチゾーンを上向きに押し上げて、重力が引き下げられるようにリリースします。 トランジスタは、キャッチゾーンをオーバーラップし、ドレインを破棄します。 100%の到達は成功します。 お問い合わせ canFail QTEを失敗させるのは本当です。

パラメーター


type GravityBarQteParams = {
    progressStartValue?: number // 進行値(0-100)を開始します。 default: 30の特長
    catchZoneSize: number // プレイヤーのキャッチゾーンのサイズはバーの分数(0, 0-1)です。 default: 0.25 の
    moverSpeed: number // 移動体がバーに沿って移動する速度(must be > 0)。 default: 3
    moverErraticness: number // 移動体が方向を変える方法(=より予測不可能)。 default: 0.8 リリース
    gravity: number // プレイヤーがクリックを保持していないときにキャッチゾーンを下方に引きます。 default: 1の特長
    riseSpeed: number // プレイヤーがクリックしている間、キャッチゾーンの上下力。 default: 1.5の
    progressGainPerSecond: number // 移動体がキャッチゾーン内にある間、1秒あたりの進行状況。 default: 8の特長
    progressDrainPerSecond: number // 移動体がキャッチゾーン外にいる間、毎秒失われた進行。 default: 4の特長
    canFail: boolean // True なら、進捗が 0 に達すると QTE が失敗します。 それ以外の場合は 0 で進捗クランプを処理します。 default:偽り
    description: CustomTextStyling // QTEのプロンプトとして示されている豊富なテキスト。 default: [{ str: ”Hold to catch!” の動画です。
    icon?: string // ムーバーにアイコンが表示されます。 default:「モーンフィッシュ」
}

Sensible デフォルト


api.addQTE(playerId, {
    type: "gravityBar",
    parameters: {
        progressStartValue: 30,
        catchZoneSize: 0.25,
        moverSpeed: 3,
        moverErraticness: 0.8,
        gravity: 1,
        riseSpeed: 1.5,
        progressGainPerSecond: 8,
        progressDrainPerSecond: 4,
        canFail: false,
        description: [{ str: "Hold to catch!" }],
        icon: "Moonfish",
    },
})

precisionBar


マーカーはバーに沿って前後に振動します。 中心街にある成功ゾーン。 プレイヤーはワンクリックで、マーカーが成功ゾーン内にある場合は、QTEは成功します。そうしないと失敗します。 マーカーは、プレイヤーがクリックするまで、無期限に実行し続ける。

パラメーター


type PrecisionBarQteParams = {
    speed: number // 1秒あたりのフルバー幅のマーカーの速度(1.0 = 1秒あたりの1つの完全な広がり)。 default:0.5の
    successZoneSize: number // 成功ゾーンとしてカウントするバーの割合, 中央に集中 (つまり > 0, 0-1, 例えば 0.15 = 15%). default: 0.15 - ベストプライス ▷ FC-Moto
    label: CustomTextStyling // QTEのプロンプトとして示されている豊富なテキスト。 default: [{ str: マーカーが緑色のゾーン内にあるときにクリックしてください。]
    icon?: string // マーカーにアイコンが表示されます。 default: "" の
    scale?: number // アイコンのマルチプライヤー(must be > 0)をスケールします。 default: 1の特長
    rotation?: number // アイコンの度に回転(≥0である)。 default: 0 の特長
}

Sensible デフォルト


api.addQTE(playerId, {
    type: "precisionBar",
    parameters: {
        speed: 0.5,
        successZoneSize: 0.15,
        label: [{ str: "Click when the marker is within the green zone." }],
        icon: "",
        scale: 1,
        rotation: 0,
    },
})

rhythmClick


外輪は固定内輪に向かって縮小します。 プレイヤーは2つの重複時にクリックする必要があります。 各クリック数がカウントされます requiredSuccesses. ウィンドウを欠く(クリックしすぎて、クリックせずに円を渡すか) ミスとしてカウントします。 お問い合わせ maxMisses QTE がフェイルZZ をセットし、上回っています。そうしないと、別の試みの円をリセットするだけです。

パラメーター


type RhythmClickQteParams = {
    requiredSuccesses: number // QTE(正の整数である)を完了するのに必要な成功したクリックの数。 default:5の
    shrinkDurationMs: number // 外側の円のミリ秒単位で、最大サイズから中央まで縮小します(ただし、0)。 default: 1200の
    toleranceFraction: number // 内輪の半径の分岐は、成功したオーバーラップとしてカウントします(=> 0、0-1、例えば0.15 = ±15%)。 default: 0.15 - ベストプライス ▷ FC-Moto
    maxMisses?: number // 失敗する前に許される最高のミス。 省略した場合は、無制限のミスが許されます(非負の整数である必要があります)。 default: 3
    label: CustomTextStyling // QTEのプロンプトとして示されている豊富なテキスト。 default: [{ str: 円を揃えるとクリック!]
    icon?: string // 円の中心に表示されたアイコン。 default: "" の
}

Sensible デフォルト


api.addQTE(playerId, {
    type: "rhythmClick",
    parameters: {
        requiredSuccesses: 5,
        shrinkDurationMs: 1200,
        toleranceFraction: 0.15,
        maxMisses: 3,
        label: [{ str: "Click when the circles align!" }],
        icon: "",
    },
})

使用方法


QTEを始める


const qteId = api.addQTE(playerId, {
    type: "progressBar",
    parameters: {
        progressDecreasePerTick: 0.075,
        progressPerClick: 7,
        canFail: false,
        description: [{ str: "Click repeatedly to complete!" }],
        clickIcon: "fa-solid fa-computer-mouse",
    },
})

結果の処理


onPlayerFinishQTE(playerId, qteId, result) {
    if (result) {
        // プレイヤーの成功
    } else {
        // プレイヤーの失敗
    }
}

QTEのキャンセル


api.deleteQTE(playerId, qteId)

アクティブQTEsをチェックする


const hasQTE = api.hasActiveQTE(playerId)
