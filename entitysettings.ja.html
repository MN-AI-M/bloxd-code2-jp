エンティティの特長コンテンツ


An "エンティティ設定」は、プレイヤーが別のプレーヤーを見たり、別のプレーヤーとやり取りしたりする方法に影響します。エンティティお問い合わせ E.g. プレイヤー1は、otherEntitySettingお問い合わせエンティティ2 は 0.5 に設定された不透明度として。 つまり、プレイヤー1は見ますエンティティ2 部分的に参照スルーとして. プレイヤー1は、プレイヤー2が対象プレイヤーです。 お問い合わせAPIメソッドは変更できますエンティティ settings: 
/**
 * 特定のエンティティに対する全プレイヤーの他エンティティ設定を、指定した値に設定します。
 ※includeNewJoiners=trueは、ゲームに参加する新しいプレイヤーがこの他のプレイヤーの設定も適用されることを意味します。
 *
 * @param {EntityId} targetedPlayerId
 * @param {Setting} settingName
 * @param {OtherEntitySettings[Setting]} settingValue
 * @param {boolean} [includeNewJoiners]
 * @returns {void}
 */
setTargetedPlayerSettingForEveryone(targetedPlayerId, settingName, settingValue, includeNewJoiners)

/**
 * ゲーム内の全プレイヤー、モブ、Personメッシュに対するプレイヤーの他エンティティ設定を設定します。
 * includeNewJoiners=trueは、プレイヤーが新しい参加者に適用される設定を持っていることを意味します。
 *
 * @param {PlayerId} playerId
 * @param {Setting} settingName
 * @param {OtherEntitySettings[Setting]} settingValue
 * @param {boolean} [includeNewJoiners]
 * @returns {void}
 */
setEveryoneSettingForPlayer(playerId, settingName, settingValue, includeNewJoiners)

/**
 * 特定のエンティティに対するプレイヤーの他エンティティ設定を設定します。
 *
 * @param {PlayerId} relevantPlayerId
 * @param {EntityId} targetedEntityId
 * @param {Setting} settingName
 * @param {OtherEntitySettings[Setting]} settingValue
 * @returns {void}
 */
setOtherEntitySetting(relevantPlayerId, targetedEntityId, settingName, settingValue)

/**
 * 特定のエンティティに対するプレイヤーの複数の他エンティティ設定を設定します。
 *
 * @param {PlayerId} relevantPlayerId
 * @param {EntityId} targetedEntityId
 * @param {Partial<OtherEntitySettings>} settingsObject
 * @returns {void}
 */
setOtherEntitySettings(relevantPlayerId, targetedEntityId, settingsObject)

/**
 * 特定のエンティティに対するプレイヤーの他エンティティ設定の値を取得します。
 *
 * @param {PlayerId} relevantPlayerId
 * @param {EntityId} targetedEntityId
 * @param {Setting} settingName
 * @returns {OtherEntitySettings[Setting]}
 */
getOtherEntitySetting(relevantPlayerId, targetedEntityId, settingName)

/**
 * 特定のエンティティに対するプレイヤーの他エンティティ設定を、ゲームの既定値に戻します。
 *
 * @param {PlayerId} relevantPlayerId
 * @param {EntityId} targetedEntityId
 * @param {Setting} settingName
 * @returns {void}
 */
setOtherEntitySettingToDefault(relevantPlayerId, targetedEntityId, settingName)

利用可能なエンティティ settingsの完全なリストは次のとおりです。

canAttack


Typeの: boolean
Defaultの: false
関連するプレイヤーがこのエンティティを攻撃できるかどうか、エンティティが不可解であるかどうか。 また、エンティティがピック可能なので、プレイヤーがランズを狙います - 対話可能として、エンティティが有効なターゲットであることなしで目的とすべき設定です。

canSee


Typeの: boolean
Defaultの: true
エンティティが関連するプレイヤーによって見ることができるかどうか

colorInLobbyLeaderboard


Typeの: string
Defaultの: ""
ロビーのリーダーボードのプレーヤーの色。

hasPriorityNametag


Typeの: boolean
Defaultの: false
プレイヤーが優先ネームタグを持っているかどうか

インタラクティブ


Typeの: boolean
Defaultの: false
このエンティティ (右クリック / 対話バインド / モバイルタップ) が相互作用としてカウントするかどうか。 まさにaltアクションが消費されると、エンティティと保持されたスロートは使用せず、onPlayerAltActionはターゲットとしてそれと火を燃やします。 装飾的なエンティティで偽りを残して下さい、またはそれらはプレーヤーの入力を飲みます。
また、エンティティがピック可能なので、エンティティはcanAttackなしでやりとりすることができます。プレイヤーの目的はそれの上に着陸しますが、スイングや撮影は何もしません。
モーブにもたらす、保持されたアイテムやネイティブ収穫、乗り物、ペットの行動を優先する。 ネイティブアクションパケットは、エンティティのやりとりが可能なサーバーによって拒否されます。

interactionPrompt


Typeの: string | CustomTextStyling
Defaultの: null
関連するプレイヤーがこのエンティティを見ている間、クロスヘアによって示されている相互作用プロンプトにラベルを置きます。例えば、「オープンショップ」。 null を左にすると、プロンプトが "Interact" を読み込みます。 エンジンは、プレイヤーの対話キーを横に描画するので、どのボタンを押してもやりとりするのかを書きます。 対話可能なセットを持つエンティティでのみ使用し、タッチスクリーンに表示されていないため、キーが表示されません。

killfeedColour


Typeの: string
Defaultの: ""
キルフェードの色。 他の人のために自分自身と赤のために青にデフォルト.

lobbyLeaderboardTags


Typeの: ChatTags
Defaultの: null
ロビーのリーダーボードにあるプレーヤーの名前の左にあるタグ。

lobbyLeaderboardValues


Typeの: LobbyLeaderboardValues
Defaultの: {}
リーダーボードの価値。

meshScaling


Typeの: EntityMeshScalingMap
Defaultの: {}
メッシュノードのスケーリング、api.scalePlayerMeshNodes

multilineTextBox


Typeの: MultilineTextBox
Defaultの: null
エンティティの横のテキストを表示するための複数行テキスト情報: 
 {
     content: (CustomTextStyling[number] | RankInfo)[]    // テキストコンテンツの配列
     backgroundColor?: string                             // 背景色
     animateIn?: boolean                                  // テキストが文字ごとにアニメーションするかどうか
     visibleThroughWalls?: boolean                        // このtextのcanSeeNametagsThroughWallsをオーバーライド:真はブロックとエンティティの上にそれを引きます、偽はそれらを隠すことを可能にします
 }


エンティティの独自のメッシュが、エンティティのhideDistはテキストにも適用されます。

nameColour


Typeの: "default" | "yellow" | "lime" | "green" | "aqua" | "cyan" | "blue" | "purple" | "pink" | "red" | "orange"
Defaultの: "default"
エンティティの名前の色。

nameTagInfo


Typeの: NameTagInfo
Defaultの: null
playerのネームタグ情報: 
 {
     backgroundColor?: string
     content?: StyledText[]
     subtitle?: StyledText[]
     subtitleBackgroundColor?: string
     minLighting?: number
     healthbar?: { display?: "always" | "never" | "onDamage"; height?: FontSize; backgroundColour?: string; foregroundColour?: string | { healthFraction: number; colour: string }[] }
     border?: { colour: string; style?: "solid" | "glow" | "double"; width?: FontSize; applyTo?: "both" | "nametag" | "healthbar" }
 }


オパシティ


Typeの: number
Defaultの: 1
エンティティの不透明度
フラクショナルな値がダイザリングを使用する
0 オパシティはエンティティを隠しますが、その名前のタグは隠しません

overlayColour


Typeの: string
Defaultの: null
エンティティが傷つけるとき、赤い色合いのように、設定されたとき、エンティティに色の色合いを提供します。

showDamageAmounts


Typeの: boolean
Defaultの: true
エンティティを撮影するときのダメージ量が見えるかどうか

zIndex


Typeの: 0 | 1
Defaultの: 0
エンティティのレンダリング順序、より低いものの上の高いzIndexのレンダリング。
