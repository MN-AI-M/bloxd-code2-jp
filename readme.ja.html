コード API


コードブロックを右クリックし、コードボードに押し込むと、Javascriptを実行できます。 世界のロビーの所有者にのみ利用可能です。 javascript は Bloxd.io ゲーム api とやり取りできます。
お問い合わせ 私たちのコード あなたが遭遇する問題や追加を見たい機能を報告するために。

コードブロック


  • 世界の所有者は、創造的なメニューで検索することにより、これらを見つけることができます
  • 追加する必要はありません press to code、コードボードのテキストのみが必要で、自動的に削除されます。
  • コードエディタを開くことなくコードを実行したい場合、右クリックでコードブロックをトリガーできます。 press to code 代わりにボード

ボード


  • ボードから始めることができます press to code 右クリックするとjavascriptを実行します。
  • 通常は、配置後にコードボードを編集することはできませんが、スペースを前に置くことによって、現在この周りで作業することができます press to code.
  • ボードは少量のテキストのみを許可します。代わりにコードブロックを使用するか、複数のボードを使用してこれを回避できます。

インフォメーション


  • グローバル変数 myId そして、 playerId コードを実行しているプレイヤーのIDを保存します。
  • グローバル変数 thisPos 現在実行中のコードブロックの位置を格納するか、コードボードにプレスします。
  • myId, playerId, thisPos そして、 ownerDbId すべての定義は api
  • 使える api.log or console.log 印刷およびデバッグのため(同じ事をします)。
  • 使える Date.now() 代わりに api.now() あなたが好むならば、両方はミリ秒の時間を返します。
  • コメント /* コメント */ 仕事, しかし、コメントのような // コメント 今は仕事しません。

事例紹介


プレイヤーjumpを作るためのコードブロック: 
f = api.setVelocity(myId, 0, 9, 0)

playerをプッシュ: 
api.applyImpulse(myId, 9, 0, 9)

yourselfにオレンジ色のメッセージを送って下さい: 
api.sendMessage(myId, "text", { color: "orange" })

textの飛行の作成: 
const speed = 100
api.sendFlyingMiddleMessage(myId, ["Message to display"], speed)

playersにメッセージを送信する: 
api.broadcastMessage("announcement", { color: "red" })

プレーヤーの健康を99に設定し、古いhealthをプリント: 
const oldHealth = api.getHealth(myId)
api.setHealth(myId, 99)
api.log("Old Health:", oldHealth)

自分のIDを除くプレーヤーIDsを取得する機能を定義します。 
getOtherIds = () => {
    const ids = api.getPlayerIds()
    const otherIds = []
    for (const id of ids) {
        if (id !== myId) {
            otherIds.push(id)
        }
    }
    return otherIds
}

他のプレイヤーがzombiesのように見えるようにするために上記の機能を使用して下さい: 
for (const otherId of getOtherIds()) {
    api.setPlayerPose(otherId, "zombie")
    api.changePlayerIntoSkin(otherId, "head", "zombie")
}

wizardsの浮遊のようなすべてのプレーヤーの一見を作って下さい: 
for (const playerId of api.getPlayerIds()) {
    api.setPlayerPose(playerId, "driving")
    api.changePlayerIntoSkin(playerId, "head", "wizard")
}

/**
 * ANIMATION SCHEMA TYPES
 *
 ※エンティティがタイムパスとして位置づける方法を説明するアニメーションスキーマ。
 ※エンティティのスケルトンの各ノードではアニメーションタイムラインを定義しています。
 ※タイムラインは「キーフレーム」の配列です。
 *キーフレームは重要な位置を表します。これがジャンプアニメーションの場合、
 *キーフレームの例はジャンプのピークになります。
 *
 *アニメーション中にエンティティが配置される方法を決定するとき、
 ※通常は2つのキーフレーム間で自分自身を見つけます。
 *例えば、キーフレームが時差0.0、0.5、1.0の場合、
 *現在の時刻の分率は0.3で、中間の地面を見つける必要があります
 ※第1と第2のキーフレーム間。
 * このプロセスは、補間、または "lerping" として知られています。
 * デフォルトの方法はリニアラッピングです。2つのポイント間の直線を描画します。
 *代替品はスプリンティングです。曲線を描く。
 */
export type AnimationSchema = {
    animationDurationMs: number
    loop?: LoopModeSchema
    nodeAnimations?: NodeSkeletonAnimationSchema
}

type LoopModeSchema = boolean | "hold-on-last-frame"

type NodeSkeletonAnimationSchema = Record<NodeName, NodeAnimationSchema>

type NodeAnimationSchema = {
    timeline: AnimationTimelineSchema
}

type AnimationTimelineSchema = KeyframeSchema[]

type KeyframeSchema = {
    timeFraction: number
    rotation?: LerpPointSchema // ローテーションはラジアンで想定されます。
    position?: LerpPointSchema // 位置は、メッシュローカル単位でオフセットします。 (0, 0, 0) は、ノードの残りのポーズを意味します。
}

/**
 ※「プレ」と「ポスト」のポイントは、不連続を許すために存在します。
 */
export type LerpPointSchema =
    | Point
    | {
            lerpMode?: LerpModeSchema
            point: Point
      }
    | {
            lerpMode?: LerpModeSchema
            pre: Point // 点に向かって立ち向かうと、その先へ向かう。
            post: Point // 点から離れたところは、その投稿から離れる。
      }

/**
 ※「キャムル・ローム・スプライン」は、スプリンティングの形態で、2点間の曲線を描く。
 */
export type LerpModeSchema = "linear" | "catmull-rom-spline"

/**
 * BLOCKBENCH ANIMATION SCHEMA TYPES
 *
 * ネイティブBlockbenchアニメーションをサポートしています。 コピーや貼り付けのケースだけ
 * JSONファイルからの特定のアニメーション。
 *
 * 注目すべきdifferences:
 * - Blockbench アニメーションは時刻の分数を使用しません。 代わりに、絶対時間を使用します。
 * - 時刻の単位はミリ秒ではなく秒です。
 * - 角の単位は、放射状ではない程度です。
 * - X軸は鏡面に映ります。
 */
export type BlockbenchAnimationSchema = {
    animation_length: number // 秒単位でアニメーションの持続時間。
    loop?: BlockbenchLoopModeSchema
    bones?: BlockbenchBonesAnimationSchema
}

type BlockbenchLoopModeSchema = boolean | "hold_on_last_frame"

type BlockbenchBonesAnimationSchema = Record<NodeName, BlockbenchBoneAnimationSchema>

type BlockbenchBoneAnimationSchema = {
    rotation?: BlockbenchAnimationTimelineSchema // ブロックベンチの回転は度合いです。
    position?: BlockbenchAnimationTimelineSchema // ブロックベンチの位置はメッシュローカル単位でオフセットします。残りのポーズは(0, 0, 0)です。
}

type BlockbenchAnimationTimelineSchema = Point | Record<TimestampString, BlockbenchAnimationFrameSchema>

/**
 ※「プレ」と「ポスト」のポイントは、不連続を許すために存在します。
 */
export type BlockbenchAnimationFrameSchema =
    | Point
    | {
            lerp_mode?: BlockbenchLerpModeSchema
            pre?: Point // 点に向かって立ち向かうと、その先へ向かう。
            post: Point // 点から離れたところは、その投稿から離れる。
      }

/**
 ※「カタムロム」はスプリンの形態で、2点間の曲線を描く。
 */
export type BlockbenchLerpModeSchema = "linear" | "catmullrom"
