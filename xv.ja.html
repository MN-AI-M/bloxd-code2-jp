サウンドエフェクト


音響効果は短いオーディオクリップ(例えば、足ステップ、ヒット曲、周囲の音)です。 利用する playSound, or broadcastSound APIメソッド。

APIの特長使用方法


// 特定のプレーヤーのための音を再生する
api.playSound(playerId, soundName, volume, rate, posSettings?)

// すべてのプレーヤーに音をブロードキャスト(またはすべてを除く)
api.broadcastSound(soundName, volume, rate, posSettings?, exceptPlayerId?)

パラメーター:
  • soundName: 以下に掲げる音名の1つ
  • volume: 0.0 to 1.0
  • rate: 再生速度(1.0 = 通常の速度、0.5 = 半速度、2.0 = ダブルスピード)
  • posSettings (任意): { playerIdOrPos: EntityId | number[], maxHearDist?: number, refDistance?: number }
Tipの: ランダムに似たような音をしたい場合、音名から数字のサフィックスを削除します(例:、使用) "grass" 代わりに "grass1").

ミュージック


音楽トラックはバックグラウンドアンダンスのためのより長いオーディオです。 利用する setClientOption APIメソッドと "music" オプション。

APIの特長使用方法


// 特定のプレーヤーのために曲を再生
api.setClientOption(playerId, "music", "Adigold - Dreamless Sleep")

// 現在の曲を停止する
api.setClientOption(playerId, "music", null)

Noteの: サウンドエフェクトとは異なり、曲はクライアントのオプションではなく、 playSound API. 1つの曲のみがプレーヤー1回再生されます。新しい曲を設定すると、現在の曲が置換されます。
