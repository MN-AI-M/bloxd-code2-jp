Mob設定


これらは、モブの行動、それらがどのように見えるか、そして彼らがどのように聞こえるかに影響を与えます。 これらは、特定のタイプのすべてのモブに対して、パーモブベースまたはデフォルトで設定できます。 これらのAPIメソッドは、mobi settingsを変更することができます: 
/**
 * mob 設定のデフォルト値を返します。
 *
 * @param {TMobType} mobType
 * @param {TMobSetting} setting
 * @returns {MobSettings<TMobType>[TMobSetting]}
 */
getDefaultMobSetting(mobType, setting)

/**
 * デフォルト値をモブ設定に設定します。
 *
 * @param {TMobType} mobType
 * @param {TMobSetting} setting
 * @param {MobSettings<TMobType>[TMobSetting]} value
 * @returns {void}
 */
setDefaultMobSetting(mobType, setting, value)

/**
 * 特定のモブの設定の現在の値を取得します。
 *
 * @param {MobId} mobId
 * @param {TMobSetting} setting
 * @param {boolean} [returnDefaultIfNotOverridden] - If true, return the default setting if not overridden.
 * @returns {MobSettings<MobType>[TMobSetting]}
 */
getMobSetting(mobId, setting, returnDefaultIfNotOverridden)

/**
 * 特定のモブの設定の現在の値を設定します。
 *
 * @param {MobId} mobId
 * @param {TMobSetting} setting
 * @param {MobSettings<MobType>[TMobSetting]} value
 * @returns {void}
 */
setMobSetting(mobId, setting, value)

モブAI


モブのAIstate は、その行動を決定します。例えば、それはまだ立っていうか、直線で歩くか、誰かを追い、座標に向かって動くかなどです。 お問い合わせAPImob's を変更できるメソッドAI state: 
/**
 * 与えられたモブのための現在のAIの状態を得ます。
 *
 * @param {MobId} mobId
 * @returns { { state: MobAiState; params: MobAiStateParams<MobAiState> } }
 */
getMobAiState(mobId)

/**
 * 与えられたモブのための現在のAIの状態を置きます。
 ※AIの状態は、ライフフォームのIDなどの文脈が必要になります。
 *
 * @param {MobId} mobId
 * @param {TState} state
 * @param {MobAiStateParams<TState>} params
 * @returns {void}
 */
setMobAiState(mobId, state, params)

利用可能なモブAIの状態とparametersの完全なリストは次のとおりです。
ステート説明パラメーター
idleモブはまだ立っていますが、それはまだその環境の意識を持っています。<br>exampleのため:モブが敵対的であるならば、それはまだ近くの選手を追い、攻撃します。null
disabledモブは静止画であり、環境の意識はなく、<br> 改善しても反応しません。null
idleBeforeTurningmob は stood まだ (idle) であり、 ターンする。null
turningモブはランダムで新しい方向を選び、それを直面するために回しています。null
idleBeforeWalkingモブは静止画(アイドル)であり、歩いています。null
walking向かう方向にモブが歩く。null
runningAwayモブはターゲットライフフォームから離れて実行されます。{ targetId: LifeformId }
chasingモブはターゲットライフフォームを追いかけています。{ targetId: LifeformId }
turningBeforeChargingチャージアタックモブは静止画であり、 turnRate ターゲットに直面するまで、<br>at はターゲットの現在の位置と遷移を捉える charging.{ targetId: LifeformId }
chargingチャージアタックモブは、ターゲットのライブポジションのミッドダッシュを無視して、状態をエンターしたときに捕獲されたターゲットの位置でまっすぐにダッシュされます(したがって、充電は有効です)。{ targetId: LifeformId }
followingモブはターゲットライフフォームに従います。<br> 内にあると止まります minFollowingDistance (mob 設定) 対象の、<br> および外部であれば対象への通信 maxFollowingDistance ターゲットの(移動設定)。{ targetId: LifeformId }
watchingモブは、まだターゲットを見ている立証です。{ targetId: LifeformId }
walkingToPositionモブは位置に向かって歩いています。<br> 内にあると止まります stoppingRadius 位置の(移動設定)。{ pos: Pos }
runningToPositionmob は position.<br> に向かって実行されます。 内にあると止まります stoppingRadius 位置の(移動設定)。{ pos: Pos }
