車両設定


車は、ボートやカートのような乗り物です。 物理タイプは、何かの動きを記述する設定のリストです。その重量、速度、ステアリングなど。 2つはseparateです:車に乗ることは普通あなたの物理タイプを変えます、プレーヤーは何でも乗らなくても1を与えられます。
各設定の値は3つのstepsで解決されます:
1。 デフォルトは、すべてが同じです。 2.物理タイプ(例: CAR) それらの一部を変更します。 3. 層(例えば。 OFF_ROADER) もう少し変更します。
1つの車両は、すべての3を打つ設定のために独自の値を与えることもできますが、誰が乗るのにも役立ちます。
いくつかの設定 (canAutoStep, speedMultiplier) はブロックを最初に命名することによって、同時に 1 つのブロックの値を指定できます - "IceCanAutoStep". これにより、ライダーがそのブロックに立っているときに適用されます。
これらのAPIメソッドは、車両を流し、プレイヤーmovesがどのように変化するかを変更します。 
/**
 ※プレイヤーの物理状態(車種・タイヤ)を設定します。
 *
 * BOAT、GLIDER、CAR)、`tier`の`null`のデフォルトを最初に持っているタイプのため
 * 層 (0). ティアのないタイプ(例)DEFAULT) は、`null`ティア。
 *
 * @param {PlayerId} playerId
 * @param {PlayerPhysicsState<PhysicsType>} physicsState
 * @param {[number, number, number]} [positionOffset] - Optional offset to adjust the player's collision box
 * @returns {void}
 */
setPlayerPhysicsState(playerId, physicsState, positionOffset)

/**
 * プレーヤーの物理状態を取得する
 *
 * @param {PlayerId} playerId
 * @returns {PlayerPhysicsState<PhysicsType>}
 */
getPlayerPhysicsState(playerId)

/**
 ※車内でプレイヤーに座る座席 0 ドライブ; 他の座席は動き制御なしで車に続きます。
 * プレイヤーは、現在の車両を離れ、要求されたシートを占有する人を交換します。
 *
 * @param {PlayerId} playerId
 * @param {EntityId} vehicleEId - A spawned vehicle or a rideable mob.
 * @param {number} [seatIndex] - Seat index (default 0).
 * @returns {void}
 */
setPlayerVehicle(playerId, vehicleEId, seatIndex)

/**
 ※ 乗っているものからプレイヤーを脱いで、どこにあるかをドロップします。 彼らがいるなら何もしない
 ※乗らないこと。
 *
 * @param {PlayerId} playerId
 * @returns {void}
 */
exitPlayerVehicle(playerId)

/**
 ※エンティティの座席レイアウト - 最低1つの運転席(インデックス0)、オプションでもっと
 ※ 乗務員の席は後日となります。 浮上した車両のデフ(`VehicleMeshEntityDef.seats`、
 * 物理タイプ/層の`riderOffset`のデフォルトで1つの運転者の座席に戻って落ちて下さい)またはa
 * 乗車可能なモブのオーバーライド(`getMobVehicleSeats`、`rideHeight`に戻って落ちる)。 投げるなら
 ※`vehicleEId`は車輌ではありません。
 *
 * @param {EntityId} vehicleEId
 * @returns {VehicleSeat[]}
 */
getVehicleSeats(vehicleEId)

/**
 * 特定の車両エンティティの物理設定の現在の値: を介して設定された値
 * `setVehicleSetting`は、オーバーライドされ、そうでなければ(`returnDefaultIfNotOverridden`の場合)タイプ/層
 * 車両の物理状態からデフォルト。 `getMobSetting`のミラー。
 *
 *タイプ/層から読み込まれないデフォルトは、その乗車高さから来るモブの`riderOffset`です。
 *
 ※1ブロックの設定(例:`"IceCanAutoStep"`)は、ブロックがリストされていないと`undefined`です。
 ※ブロックは設定がオフではなく設定を変更しません。
 *
 * @param {EntityId} vehicleEId
 * @param {TSetting} setting
 * @param {boolean} [returnDefaultIfNotOverridden]
 * @returns {SettableVehicleSettingValue<TSetting>}
 */
getVehicleSetting(vehicleEId, setting, returnDefaultIfNotOverridden)

/**
 * 特定の車両のエンティティの物理設定をオーバーライドし、そのタイプ/層のデフォルトを置き換えます
 ※車両ライダーオーバーライドは、現在車がいるとき、共有ブロックス上に保存されます。
 *ライダーは、そのライダーのクライアントにレプリカ。 `setMobSetting`のミラー。
 *
 * ブロックを最初にネーミングすることで、1つのブロックに対して設定をオーバーライドすることもできます。
 * `setVehicleSetting(boatId, "IceCanAutoStep", true)`。 マッチングのエントリーとして保存されます。
 * `<setting>ByBlock`の記録は、物理が事前に入力されたブロックのルックアップとして読み込まれる。
 *
 * @param {EntityId} vehicleEId
 * @param {TSetting} setting
 * @param {SettableVehicleSettingValue<TSetting>} value
 * @returns {void}
 */
setVehicleSetting(vehicleEId, setting, value)

/**
 * 乗り物車をスポーンして、プレイヤーはaltアクションでマウントできます。
 ※エンティティのメッシュ数に制限があります。
 ※WARNING:「onPlayerAttemptSpawnVehicle」または「onWorldAttemptSpawnVehicle」のいずれかの試合コールバックが呼び出されます
 ※「spawnerId」が提供されているかによって異なります。 これらのコールバック中のこの関数を呼び出すと、無限の再帰が危険になります。
 *
 * @param {MeshEntityVehicleType} vehicleType
 * @param {number} x
 * @param {number} y
 * @param {number} z
 * @param {VehicleSpawnOpts} [opts] - Includes:
 * - spawnerIdふりがなID車をスポーンしたプレーヤーの。 車はそれらから離れて直面します。
 * @returns {PNull<EntityId>} - null if the vehicle could not be spawned, otherwise the entity ID of the vehicle.
 */
attemptSpawnVehicle(vehicleType, x, y, z, opts)

/**
 ※車両の状態を消し、世界から削除します。
 * 常に成功します。
 *
 * @param {EntityId} vehicleId
 * @returns {void}
 */
despawnVehicle(vehicleId)

開催車両


また、世界中に配置するのではなく、プレイヤーに取り付けられます。 マッチングアイテムが保持されている限りアクティブ - 何か他のものや乗り継ぎの端に交換します。

すべての車両設定とデフォルトはから始まります。 有効期間 pose 値のリスト SKINS_AND_POSES.md, 有効 effect.icon 値で ICONS.md.
各例は、idがから来た1つの車両の設定を変更します。 attemptSpawnVehicle.

airborneFallSpeedLimit


Typeの: PNull<FallSpeedLimitOpts>
Defaultの: null
飛行中に落ちる速度をキャップします。 使用時のみ airborneMovement is "heading". null = フルスピードで落ちる。 お問い合わせ FallSpeedLimitOpts. 
// ドロップではなく4ブロックで漂流するホバークラフト
api.setVehicleSetting(hovercraftId, "airborneMovement", { model: "heading" })
api.setVehicleSetting(hovercraftId, "airborneFallSpeedLimit", { maxFallSpeed: 4, slowDownSeconds: 0.15, compensateGravity: true })

airborneMode


Typeの: PNull<AirborneModeOpts>
Defaultの: null
中空と下降を繰り返します。 支えられた動き types: GLIDING そして、 FLOATING. null = 飛ぶことはできません。 お問い合わせ AirborneModeOpts. 
// ホバークラフトをグライダーモードにし、崖を降りて飛行する
api.setVehicleSetting(hovercraftId, "airborneMode", { activeMovementType: MovementType.GLIDING, durationMs: null, exitsVehicleOnEnd: false })

airborneMovement


Typeの: PNull<AirborneMovementOpts>
Defaultの: null
飛行中に移動する方法。 null = それは地面で行う同じ方法を盗みます。 お問い合わせ AirborneMovementOpts. 
// 飛行ホバークラフトはカメラに従う、グライダーのように
api.setVehicleSetting(hovercraftId, "airborneMovement", {
    model: "cameraDirection",
    maxSpeed: 13,
    minSpeed: 0.5,
    pitchAcceleration: 0.0125,
    friction: 0,
    impulseDecayTicks: 100,
    biasMagnitude: 1.5,
    excessVelocityBleedPerTick: 0.5,
})

airSpeedMultiplier


Typeの: number
Defaultの: 1
空気中に使用したエキストラスピードマルチプライヤー。 
// 中身のけいれんがをまかせたカート
api.setVehicleSetting(kartId, "airSpeedMultiplier", 0.2)

canAutoStep


Typeの: boolean
Defaultの: true
単一のブロックに設定することもできます - 参照 {BlockName}CanAutoStep.
ライダーがジャンプするのではなく、それ自体で1ブロックのステップを登るかどうか。 
// ライダーはそれを転がすのではなく、すべてのカーブをジャンプさせます
api.setVehicleSetting(carId, "canAutoStep", false)

{BlockName}CanAutoStep


Typeの: boolean
Defaultの: unset - 物理型リストのブロックだけ canAutoStepByBlock 以下は、自分の価値で始まります。
settingに続くブロックとして名前を付けました: "IceCanAutoStep", "Red ConcreteCanAutoStep".
オーバーライド canAutoStep ブロック名で特定のブロックの場合。 リストされていないブロックの使用 canAutoStep. 
// 氷の上に乗る船は、他にはない
api.setVehicleSetting(boatId, "canAutoStep", false)
api.setVehicleSetting(boatId, "IceCanAutoStep", true)

canRun


Typeの: boolean
Defaultの: true
ライダーがスプリントするかどうか。 
// ライダーは、自分の速度の上にカートをスプリントしてみましょう
api.setVehicleSetting(kartId, "canRun", true)

disableBaseMovement


Typeの: boolean
Defaultの: false
通常のステアリング駆動の動きをオフにします。, 睡眠プレーヤーのため. 
// ゴースト train: ライダーは、すべてで操縦できません
api.setVehicleSetting(kartId, "disableBaseMovement", true)

disableFootstepSounds


Typeの: boolean
Defaultの: false
フットステップの音が沈黙しているかどうか。 
// フットステップをカートに入れる
api.setVehicleSetting(kartId, "disableFootstepSounds", false)

エフェクト


Typeの: PNull<{ name: string; icon: string; duration?: number }>
Defaultの: null
乗る限りライダーに示されているバッジ。 null = なし。 icon ゲーム内アイコンまたは 項目名。 name 物理タイプが既に使用しているものでなければなりません。 "Driving" or "Boating", ライダーが降りると、再びクリアされるので。 
// 通常のカートの代わりにオフロードアイコンでカートをバッジ
api.setVehicleSetting(kartId, "effect", { name: "Driving", icon: "Off Roader" })

fixedHeading


Typeの: PNull<number>
Defaultの: null
カメラを無視する、ラジアンで直面する方向を締めます。 null =カメラやステアリングポイントのどこにいても直面します。 
// ボートを1方向にピンし、ライダーが見えるように
api.setVehicleSetting(boatId, "fixedHeading", Math.PI / 2)

fluidDrag


Typeの: number
Defaultの: -1
どのくらいの水と溶岩が遅くなるか。 -1 世界の通常のドラッグを使用します。 
// 水を通したボート
api.setVehicleSetting(boatId, "fluidDrag", 8)

fluidDragHorizontal


Typeの: number
Defaultの: -1
fluidDrag 横方向の動きだけのため。 -1 に戻る fluidDrag. 
// 水中に散らばるのではなく、水中に車をスケートしましょう
api.setVehicleSetting(carId, "fluidDragHorizontal", 0)

fluidDragVertical


Typeの: number
Defaultの: -1
fluidDrag 上下の動きだけのため。 -1 に戻る fluidDrag. 
// ボブの代わりにゆっくりと沈むボート
api.setVehicleSetting(boatId, "fluidDragVertical", 6)

fluidSkip


Typeの: PNull<FluidSkipOpts>
Defaultの: null
石のように水を渡るのを十分速いです。 null = それは普通浮遊します。 お問い合わせ FluidSkipOpts. 
// 石のような水を渡る船のスキムを聞かせて下さい
api.setVehicleSetting(boatId, "fluidSkip", { minSpeed: 11, launchSpeedFraction: 0.4, launchApproachRate: 25 })

fluidSpeedMultiplier


Typeの: number
Defaultの: 1
水または溶岩中に使用した追加の速度マルチプライヤー。 
// 道路上の水に速く、巨大なカート
api.setVehicleSetting(kartId, "fluidSpeedMultiplier", 1)

gravityMultiplier


Typeの: number
Defaultの: 2
通常のプレーヤーと比較して、重力が引き下げる方法。 0 = それは決して落ちません。 
// すべてのジャンプの後で空気で掛かる月のbuggyのカート
api.setVehicleSetting(kartId, "gravityMultiplier", 0.5)

高さ


Typeの: number
Defaultの: 1.8
ブロックの背が高い。 
// 2ブロックのトンネルの下に収まる低周遊カート
api.setVehicleSetting(kartId, "height", 0.9)

horizontalBounciness


Typeの: number
Defaultの: 0
弾力性の壁are: 0 死者を止めて下さい、 1 すべての速度を保ちます。 スタックと bounciness クライアント オプション。 リバウンドは床速度が大きいので、バンパーが到着したよりも早く戻ってきます。 
// 死者を止めるのではなく壁を離れてpingsのバンパー車
api.setVehicleSetting(kartId, "horizontalBounciness", 0.8)

horizontalImpactCameraShake


Typeの: PNull<ImpactCameraShakeOpts>
Defaultの: null
十分に壁に当たるとカメラを揺るがします。バウンスする必要はありません。 null = 揺れません。 お問い合わせ ImpactCameraShakeOpts. 
// 車が壁を覆うとき、画面をラトル
api.setVehicleSetting(carId, "horizontalImpactCameraShake", { minSpeed: 6, intensityPerSpeed: 0.03, maxIntensity: 0.6, durationMs: 300 })

jumpMultiplier


Typeの: number
Defaultの: 1
通常のジャンプと比較して、ジャンプするときにライダーが地面をプッシュする方法。 0 =ジャンプできません。 マルチプライズ jumpAmount クライアントのオプションは、それを置き換えるのではなく、より重いタイプはより大きい必要があります 同じ高さに達する価値。 
// たくさんのバネジャージャンプでスタントカート
api.setVehicleSetting(kartId, "jumpMultiplier", 5)

landSpeedMultiplier


Typeの: number
Defaultの: 1
固体地面のまわりで使用される余分速度の乗合器。 
// 10速でドライランドに沿ってドラッグするボート
api.setVehicleSetting(boatId, "landSpeedMultiplier", 0.1)

マスコミ


Typeの: number
Defaultの: 1
重さは? 重い物は、浮遊物ではなく、周りをプッシュし、シンクに抵抗します。 
// すべての爆発が飛行を送るフェザー級カート
api.setVehicleSetting(kartId, "mass", 0.3)

maxPushDistance


Typeの: number
Defaultの: 0
目指す速度をはるかに下回る間、どれだけの硬さが押し込まれているかをキャップします。 0 =帽子無し。 
// 重いローリーは速度まで取得する時間がかかります。 ニッピーのレースカーは、すべてのキャップを持っていません
api.setVehicleSetting(lorryId, "maxPushDistance", 2)
api.setVehicleSetting(raceCarId, "maxPushDistance", 0)

minHorizontalSpeedToBounce


Typeの: number
Defaultの: 0
壁に、ブロック毎秒、ブロックに当たらない速度 horizontalBounciness お問い合わせ 0 = 任意の連絡先。 
// 壁が速度で衝突するだけ、穏やかではない屑
api.setVehicleSetting(kartId, "minHorizontalSpeedToBounce", 8)

minVerticalSpeedToBounce


Typeの: number
Defaultの: 0
1秒あたりのブロックで落下しなければならない速度 verticalBounciness お問い合わせ 0 バウンス あらゆる接触を離れて、所定の位置に弾力がある車のジグリングを残して下さい。 
// 大きい低下だけ、従って駐車されたカートはまだ坐ります
api.setVehicleSetting(kartId, "minVerticalSpeedToBounce", 5)

movementForceMultiplier


Typeの: number
Defaultの: 1
どのようにハードステアリングがそれを押します. Bigger = それはスピードアップし、より鋭く方向を変えます。 
// ほぼ瞬時にトップスピードに到達するtwitchyのカート
api.setVehicleSetting(kartId, "movementForceMultiplier", 2)

ポーズ


Typeの: PlayerPose
Defaultの: "standing"
乗車中にライダーの体が配置される方法。 
// ライダーは、座っての代わりに、このボートに戻って
api.setVehicleSetting(boatId, "pose", "sleeping")

riderOffset


Typeの: [number, number, number]
Defaultの: [0, 0, 0]
ライダーが座るところ、 [x, y, z] 車両の中央からブロックします。 有利なモブのデフォルト このタイプの値ではなく、自分の乗車高さに。 
// ブーツのように、ライダーをさらに後ろに座る
api.setVehicleSetting(carId, "riderOffset", [0, 0.25, -0.8])

speedMultiplier


Typeの: number
Defaultの: 1
単一のブロックに設定することもできます - 参照 {BlockName}SpeedMultiplier.
通常の歩く速度の乗数として、そのトップスピード。 0 = 動くことができません。 
// カートのトップスピードを2倍にし、ブーストピックアップ
api.setVehicleSetting(kartId, "speedMultiplier", 24)

{BlockName}SpeedMultiplier


Typeの: number
Defaultの: unset - 物理型リストのブロックだけ speedMultiplierByBlock 以下は、自分の価値で始まります。
settingに続くブロックとして名前を付けました: "IceSpeedMultiplier", "Red ConcreteSpeedMultiplier".
ブロック名でブロックのアンダーフット用の余分速度マルチプライヤー。 固体地面だけ、および積み重ねと speedMultiplier そして土地/流動/空気のmultiplier。 いくつかのリストされたブロックが足下にあるとき、 値 furthestから 1 勝つ。 
// 石道路を飛ぶと雪を通る車
api.setVehicleSetting(carId, "SnowSpeedMultiplier", 0.4)
api.setVehicleSetting(carId, "StoneSpeedMultiplier", 1.5)

standingFriction


Typeの: number
Defaultの: 5
ライダーがステアリングを止めたら、すぐに停止する。 Bigger = すぐに停止します。 
// ライダーがステアリングを停止した後にスライドするアイシーカート
api.setVehicleSetting(kartId, "standingFriction", 0.2)

ステアリング


Typeの: PNull<SteeringOpts>
Defaultの: null
car: 左と右は横にスライドするのではなく、それを回転させます。 null ログイン 歩いているプレーヤーのようなあらゆる方向で自由に。 お問い合わせ SteeringOpts. 
// ドリフト kart: クイックトゥターン, しかし、バックエンドステップアウトすべてのコーナー
api.setVehicleSetting(kartId, "steering", { turnRate: 3.5, corneringSpeedDamping: 0.1, gripStrength: 2, gripInFluid: false })

upwardImpulseOnUse


Typeの: number
Defaultの: 0
単一車両では変更できません - 物理型の値から常に読み込みます。
ライダーが乗り降りする気球のような車を使っている瞬間を上向きに撮影します。 0 = なし。 
// 物理/セッティング/*.ts:ライダーをより高い起動する気球
upwardImpulseOnUse: 30

verticalBounciness


Typeの: number
Defaultの: 0
床isを弾く方法: 0 平らに土地, 1 バウンスは、落とすと早く戻ります。 スタックと bounciness クライアントオプションは、同じリバウンドフロアと同じです。 horizontalBounciness. 
// 土地のたびにバウンスするスペースホッパーカート
api.setVehicleSetting(kartId, "verticalBounciness", 0.7)

verticalImpactCameraShake


Typeの: PNull<ImpactCameraShakeOpts>
Defaultの: null
床や天井の硬さに当たるとカメラを揺るがします。バウンスする必要はありません。 null = 揺れません。 お問い合わせ ImpactCameraShakeOpts. 
// オフロードが大きいジャンプを造るときの骨を揺るぐるみ
api.setVehicleSetting(offRoaderId, "verticalImpactCameraShake", { minSpeed: 3, intensityPerSpeed: 0.05, maxIntensity: 1, durationMs: 400 })

アクセス


Typeの: number
Defaultの: 0.5
ブロックの幅が広がります。 
// ワンブロックの路地にはモンスタートラックも大幅
api.setVehicleSetting(offRoaderId, "width", 1.2)

タイプ用語集


上記の設定の一部で撮影したオブジェクト形状。

SteeringOpts


type SteeringOpts = {
    /** 1秒あたりラジアンで、速度が速くなります。 Bigger = スナップピアステアリングとタイトなコーナー。 */
    turnRate: number
    /*※`0`(none)から`1`(all of it)までのハードコーナーの費用はいくらかかります。 */
    corneringSpeedDamping: number
    /**
     *地面を握る量。 `0`は氷のホバークラフトのような横方向を滑らせます;より大きい価値はそれを作ります
     ※鼻の丸角に沿ってください。 `gripInFluid`がオンである限り、固体地面だけ。
     */
    gripStrength: number
    /*※水に浮かび上がるとグリップもあるので、ボートはカートのような角にすることができます。 */
    gripInFluid: boolean
}

FluidSkipOpts


type FluidSkipOpts = {
    /** 1秒あたりのブロックで、速度が速くなります。 */
    minSpeed: number
    /*※`minSpeed`のスピードが上がります。 より大きい = 高いスキップ。 */
    launchSpeedFraction: number
    /*※水がすっきりと出る方法 Bigger = 鋭いポップ; 小さい = 遅いヘーヴ。 */
    launchApproachRate: number
}

ImpactCameraShakeOpts


type ImpactCameraShakeOpts = {
    /*※1秒あたりのブロック数で、ブロック数が切れるので、小さなバンプは無視されます。 */
    minSpeed: number
    /** 1秒あたりの余分なブロックを振る回数が加算されます。 シェイクは`0` (still)から`1` (violent)に動きます。 */
    intensityPerSpeed: number
    /**最も揺れる1つのクラッシュは引き起こすことができます。 */
    maxIntensity: number
    /** 揺れが続く長さ、ミリ秒。 */
    durationMs: number
}

AirborneModeOpts


type AirborneModeOpts = {
    /** to:`GLIDING`をグライダー、`FLOATING`を風船のために転換するどの動きのタイプか。 */
    activeMovementType: MovementType
    /** ライダーを落とす前に、フライングは、ミリ秒で続きます。 `null` = 制限なし。 */
    durationMs: PNull<number>
    /** 飛行終了もライダーオフを投げるかどうか、ポッピングバルーンは行います。 */
    exitsVehicleOnEnd: boolean
}

AirborneMovementOpts


type AirborneMovementOpts = HeadingAirborneMovement | CameraDirectionAirborneMovement

HeadingAirborneMovement


type HeadingAirborneMovement = { model: "heading" }

CameraDirectionAirborneMovement


type CameraDirectionAirborneMovement = {
    model: "cameraDirection"
    /*※最速で飛行できます。 より良いグライダーは、より大きな価値を手に入れ、ダイビングし、より鋭く登る。 */
    maxSpeed: number
    /*※一番遅くなると飛ぶことができます。 しかし、急に登る。 */
    minSpeed: number
    /** スピードを上げたり下げたりすると、速度が変化します。 Bigger = ダイブは素早くスピードを上げます。 */
    pitchAcceleration: number
    /**各ティックをドラッグすると、どのくらいのドラッグが遅くなります。 `0` = なし. */
    friction: number
    /** 燃料ブースト、またはノックバック - フライトが再び引き継ぐ前に、その勢いを保ちます。 */
    impulseDecayTicks: number
    /*※ 段落が強いので、段差が緩やかに下がります。 */
    biasMagnitude: number
    /** 撮影から残った速度は、各ティックを焼く。 */
    excessVelocityBleedPerTick: number
}

FallSpeedLimitOpts


type FallSpeedLimitOpts = {
    /*※1秒あたりのブロックで落下する最速 */
    maxFallSpeed: number
    /** 時間が経つと、数秒で限界まで遅くなります。 より小さい=しっかりしたキャッチ。 */
    slowDownSeconds: number
    /*※重力を取り戻す場合でも、重力を取り戻すと限界が遅くなるわけではありません。 */
    compensateGravity: boolean
}
