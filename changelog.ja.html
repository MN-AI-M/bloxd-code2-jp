変更履歴


APIに最新の変更をご覧いただけます。

2026年9月30日

  • interactable 今、メッシュエンティティと同じ相互作用の優先順位を与えます: onPlayerAltAction 開催された項目アクションの前に実行します。 ネイティブの収穫、取り付け、ペットの操作は、設定が真の場合に無効になります。通常のモブの動作のために偽りを残してください。

9月29日 2026年

  • 世界コードにプロジェクトスキーマを追加しました! 利用する + コードエディタの「Schematics」の横にアップロードします .bloxdschem ファイルまたはプロフィールからスナップショットを選択します。 5つの回路図に対応したプロジェクトです。
  • 追加 api.setChunkAsSchematic 空気およびブロックのデータを含む1つの完全なチャンクを、取り替えるため。 位置は、ブロックの座標は、それらのを含むチャンクを選択する copyChunk.
  • 追加 api.getSchematicDimensions() 保存された回路図の読み込み [x, y, z] 選択パッドを含む次元、。
  • @plugins/sessionBasedGame 地図とロビーが今受け入れます source: { schematic: "maps/arena.bloxdschem" } 世界の長方形の代替として。 地図は直接貼り付けられ、利用可能な配置とブロックデータ予算に適合しなければなりません。
  • プロフィールから保存されるSchematicはあります スナップショット - リンクされた回路図を編集する場合は、世界/カスタムゲームで回路図を更新する必要があります。
  • 詳細はこちら プロジェクトスキーマハウツー 事例・詳細

2026年9月10日

  • 追加された interactable エンティティの設定。 エンティティまたは mob (例えば) にそれを置きます api.setTargetedPlayerSettingForEveryone(eId, "interactable", true))interactionとしてカウントするaltの作用を作るため:altの行為は消費されます、従って保持されたブロックはエンティティおよび握られた投げることができません、および onPlayerAltAction エンティティをターゲットに火をつけます。 装飾的なエンティティのためにそれを残して下さい、またはそれらはプレーヤーの入力を飲みます。 また、エンティティのピックも可能なので、エンティティは interactable お問い合わせ canAttack off:プレイヤーの目的はそれに土地を置き、作品にやりとりしますが、スイングや撮影は何もしません。 モブでは、通常の取り付けと改ざんの動作ではなく、交換するのではなく、保留可能または消耗品は、やり取りする好みで使用されます。
  • エンティティマーク interactable プレイヤーが探している間、クロスヘアによるインタラクションプロンプトが表示され、対話アクションにバインドされたキーが表示されます(E デフォルトでは)そのため、プレイヤーはどの入力を使用するかを指示できます。 新規設定 interactionPrompt エンティティの設定は、キーの横にラベルを交換します。 api.setTargetedPlayerSettingForEveryone(eId, "interactionPrompt", "Open Shop"), デフォルト "Interact" でオフにします。 テキストや CustomTextStylingエンジンがキー自体を引くので、どのボタンが押すのではなく、相互作用が何をするかを記述し。 タッチパネルには表示されません。タップはプロンプトを必要としません。

8月18日 2026年

  • TypeScriptが世界コードに対応!
    • ファイルの名前を変更します。 index.js to index.ts TypeScriptファイルを使用する!
    • 私たちのタイプのインポート @bloxd
      • E.g. import type { PlayerId } from "@bloxd"
    • あなた自身のタイプを使用して下さい!
    • タイプチェックはサポートされ、誤ったタイプを使用している場合はエラーが表示されます。
  • 複数のファイルがサポートされています! 複数のファイル間でコードを分割して、読みやすくなります。
    • ダウンロード .js そして、 .ts ファイル
    • 使用条件 import / export シンタックスは、バージョン間でファイルをインポートできるようにします
    • index.js or index.ts MUSTはどこでもあなたのコールバックが貯えられ、輸入しないで下さい。
    • require() 構文はタイプセーフではなく、技術的に動作します。
  • 64k文字から512k文字までの合計コードサイズが増加しました。
  • カスタムゲームにバリエーションを追加!
    • 各カスタムゲームには複数のバリエーションがあります。 default デフォルトのバリエーションです。
    • api.getVariation
    • api.matchmakeToVariation
