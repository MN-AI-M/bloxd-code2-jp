ブロック名(1331ブロック)



以下にリストされている各ブロック名は、ROOTブロックです - 正確に示すように使用します(サフィックスなし)。
いくつかのブロックには、括弧内のコードで示されているメタバリアントもあります。

ROOT BLOCK: リスト通りにブロック名を正確に使用(例:「メープルドア」、「小麦」、「石」)

META VARIANTS: ブロックがブラケットにコードを持っている場合、variantsを得るためにサフィックスを追加することができます:
R = 回転→BlockName|メタ|ロッ1 |meta|rot4
O=オープン/クローズド→BlockName|meta|rot1|オープン/クローズド(Rとのコンバイン)
H = halfblockPlacement -> BlockName|meta|rot1|top or |bot or |side(R・階段付)
G = 成長 -> BlockName |ご予約
TB = treeBase -> BlockName|TreeBase|<WoodType> (例:メープルログ)TreeBase|メープル
TC = treeCanopy → BlockName TreeCanopyTO
B = 書籍 -> BlockName|meta|rot1|books1 から |books6 (R との組み合わせ)
FG = freshlyGrown → BlockName FreshlyGrownTO (収穫状態)
RT = ルート > BlockName |ルーツ(世界原産の根付き花)
LV= ラヴァ →BlockName|ラヴァ(ラバ栽培品種)
TP = トップ > BlockName |トップ(背の高い植物の半分)
GR = grassRoots → BlockName GrassRootsTO (草の根と土)
BK = ブレーク → BlockName |ブレイク(吹くアニメーション状態)
FL = 点滅 -> BlockName |点滅(アニメーション状態をフラッシュ)
SC = stairsCorner -> BlockName|meta|bot|innerLeft、innerRight、outerLeftまたはouterRight (RとHとの組み合わせ)

Examplesの:
石-> "使用"石" (ブラケットなし = バリアントなし, ルートブロックのみ)
メープルドア[O,R]→Root:「メープルドア」、Variants:「メープルドア|メタ|ロット2|オープン」など
小麦 [FG] → Root:「小麦」、Variant「小麦」|FreshlyGrown
