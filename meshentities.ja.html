メッシュエンティティ、引火&ノードメッシュアタッチメント


メッシュエンティティは、すべてのクライアントと同期されるサーバー作成の3Dオブジェクトです。 Throwables は、エンジンの組み込みのプロジェクシャル物理を使用する特殊なサブセットです。 ノードメッシュアタッチメントを使用すると、既存のエンティティの特定の骨/ノードに追加のメッシュを取り付けることができます(例えば、プレーヤーの手で武器)。

制限事項


  • エンティティのメッシュ数と作成できるスローブル数に制限があります。 attemptCreateMeshEntity フィードバック null 投げるのではなく限界に達したとき。
  • 2つの別々がありますlimits: メッシュ1個エンティティ物理なしとメッシュ用エンティティ物理(より小さい)で。

メッシュエンティティ


メッシュタイプ


次のメッシュタイプは、それぞれ異なるoptionsで利用可能です。
  • Box
  • BloxdBlock
  • Person
  • Leaderboard
  • ParticleEmitter

Box


type BoxOpts = {
    hideDist?: number
    meshOffset?: number[]
    autoRotate?: boolean
    lineToEId?: EntityId // EntityIdはラインを使用して接続します
    width: number
    height: number
    depth: number
    diffuseColor?: number[]
    emissiveColor?: number[]
    backFaceCulling?: boolean // デフォルト true
    texture?: string // ブロック名を指定できます。 すべてのブロックをラップ
    faceUV?: number[][]
    animateTexture?: boolean // True なら、`texture` はアニメーションブロック名(「Lava」、「Red Portal」など)と、そのフレームを介して Box サイクルでなければなりません。
}

BloxdBlock


type BloxdBlockOpts = {
    hideDist?: number
    meshOffset?: number[]
    autoRotate?: boolean
    lineToEId?: EntityId // EntityIdはラインを使用して接続します
    blockName: BlockNameOrId
    size: number | [number, number, number]
}

Person


type PersonOpts = {
    hideDist?: number
    meshOffset?: number[]
    autoRotate?: boolean
    lineToEId?: EntityId // EntityIdはラインを使用して接続します
    size?: number
    textures?: Partial<Cosmetics>
    pose?: PlayerPose
}

Leaderboard


type LeaderboardOpts = {
    hideDist?: number
    meshOffset?: number[]
    autoRotate?: boolean
    lineToEId?: EntityId // EntityIdはラインを使用して接続します
    leaderboard: string
    title?: string
    scoreLabel?: string
    size?: number // 3.75ブロックボードで2.5の均一スケール。 デフォルトは1です。
    width?: number // ブロックの絶対幅、サイズから派生する幅をオーバーライドします。
    height?: number // ブロックの絶対高さ、サイズから得られる高さをオーバーライドします。
}

ParticleEmitter


type ParticleEmitterOpts = {
    texture: string
    minLifeTime: number
    maxLifeTime: number
    minEmitPower: number
    maxEmitPower: number
    minSize: number
    maxSize: number
    gravity: number[]
    velocityGradients: VelocityGradient[]
    colorGradients: TimeColorGradient[] | RandomColorGradient[]
    blendMode: ParticleSystemBlendMode

    dir1?: number[]
    dir2?: number[]
}

メッシュエンティティの作成


/**
 ※エンティティのメッシュを作成してみてください。 エンティティをクライアントとメッシュ位置を同期させる。
 * setPositionを使用してエンティティの位置を置いて下さい
 ※メッシュ数に制限がございます。エンティティメッシュの最小限度が小さく、作成可能エンティティ物理を使って。
 *
 * @param {MeshType} type
 * @param {MeshEntityOpts[MeshType]} opts
 * @param {string} [name] - The default name for the nametag
 * @param {MeshEntityPhysicsOpts} [physicsOptions] - Physics Options
 * @param {EntityId} [initiatorId] - The entity that initiated the creation of the mesh entity.
 * @returns {PNull<EntityId>} - null if the entity creation failed, otherwise the entity ID.
 */
attemptCreateMeshEntity(type, opts, name, physicsOptions, initiatorId)

使用条件 api.setPosition() 作成後にエンティティを移動します。

事例紹介


赤いboxを作成します。 
const boxId = api.attemptCreateMeshEntity("Box", {
    width: 1,
    height: 1,
    depth: 1,
    diffuseColor: [255, 0, 0],
})
if (boxId) {
    api.setPosition(boxId, 10, 50, 10)
}

Bloxdブロックmeshを作成します: 
const blockId = api.attemptCreateMeshEntity("BloxdBlock", {
    blockName: "Block of Diamond",
    size: 1,
})

meshの人を作成します。 
const personId = api.attemptCreateMeshEntity("Person", {
    size: 1,
    pose: "standing",
    textures: { head: "trader_black" },
}, "Bedwars Merchant")

physicsとメッシュエンティティを作成します。 
const physicsBoxId = api.attemptCreateMeshEntity(
    "Box",
    { width: 0.5, height: 0.5, depth: 0.5, diffuseColor: [0, 255, 0] },
    "",
    {
        doPhysics: true,
        collidesEntities: true,
        collideBits: 1,
        collideMask: 1,
    },
)

メッシュエンティティの更新


/**
 * エンティティのメッシュを更新します。 非メッシュエンティティで使用した場合、何もしません。
 *
 * @param {EntityId} eId
 * @param {MeshType} type
 * @param {MeshEntityOpts[MeshType]} opts
 * @returns {void}
 */
updateMeshEntity(eId, type, opts)

api.updateMeshEntity(boxId, "Box", {
    width: 2,
    height: 2,
    depth: 2,
    diffuseColor: [0, 0, 255],
})

メッシュエンティティを削除


/**
 * メッシュエンティティを削除
 *
 * @param {EntityId} eId
 * @returns {boolean} - whether the api successfully deleted the meshEntity
 */
deleteMeshEntity(eId)

api.deleteMeshEntity(boxId)

パスワード


Throwables はエンジンの組み込みの投影システムを使用します。 各投げ可能な項目に事前定義された速度、損傷および重力があります。 これらのデフォルトをマルチプライすることができます。 velocityMult, damageMultと gravityMult パラメータ。

投げつけられる作成


/**
 ※エンティティ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.ZZ.
 * メッシュエンティティの作成と同様に、同じレート制限を使用します。
 ※ただし、ゲームでスローできるアイテムで使われる既定のスローブルシステムと物理を使用します。
 * 各投げ可能な項目にデフォルト速度、損傷および重力乗数を含む自身の行動が既にあります。
 *
 * @param {EntityId} throwerEId
 * @param {ThrowableItem} itemName - Must be an Item that is usually throwable in-engine
 * @param {[number, number, number]} position - Starting position
 * @param {[number, number, number]} direction
 * @param {number} [velocityMult] - Multiplier for the default velocity of the throwable item
 * @param {number} [damageMult] - Multiplier for the default damage of the throwable item
 * @param {number} [gravityMult] - Multiplier for the default gravity of the throwable item
 * @param {ItemAttributes} [attributes] - item attributes (currently used only for the "Boomerag" item)
 * @returns {string} - null if throwable creation failed, otherwise the entity ID.
 */
attemptCreateThrowable(throwerEId, itemName, position, direction, velocityMult, damageMult, gravityMult, attributes)

事例紹介


const pos = api.getPosition(playerId)
const { dir } = api.getPlayerFacingInfo(playerId)
const throwableId = api.attemptCreateThrowable(
    playerId,
    "Fireball",
    [pos[0], pos[1] + 1.5, pos[2]],
    dir,
    2,    // 二重速度
    1.5,  // 1.5xダメージ
)

恐ろしい削除

ブロックまたはエンティティに当たるとき、または特定の時間後に消えたときに、自動的に削除されます。 この方法で手動で削除できます。 
/**
 *自動的にそれ自身を取除く前に投げられるエンティティを削除して下さい。
 *
 * @param {EntityId} eId
 * @returns {boolean} - true if the entity was deleted, false if it was not a throwable entity
 */
deleteThrowable(eId)

api.deleteThrowable(throwableId)

ノードメッシュアタッチメント


エンティティの特定のノード(「骨」)にメッシュを取り付けたり、切り離したりします。 これは、プレーヤーの本体部品または他のエンティティノードにアイテム、エフェクト、装飾を取り付けるのに便利です。 
/**
 * エンティティからの/への添付/分離の網のインスタンス
 *
 * @param {EntityId} eId
 * @param {EntityNamedNode} node - node to attach to
 * @param {PNull<MeshType>} type - if null, detaches mesh from this node
 * @param {MeshEntityOpts[MeshType]} [opts]
 * @param {[number, number, number]} [offset]
 * @param {[number, number, number]} [rotation]
 * @returns {void}
 */
updateEntityNodeMeshAttachment(eId, node, type, opts, offset, rotation)

利用できるノード


EntityNamedNode ofです。
  • "TorsoNode"
  • "HeadMesh"
  • "ArmRightMesh"
  • "ArmLeftMesh"
  • "LegLeftMesh"
  • "LegRightMesh"

事例紹介


プレイヤーの右armにブロックを取り付けます。 
api.updateEntityNodeMeshAttachment(
    playerId,
    "ArmRightMesh",
    "BloxdBlock",
    { blockName: "Block of Diamond", size: 0.3 },
    [0, -0.5, 0],  // オフセット
    [0, 0, 0],     // 回転速度
)

プレイヤーのheadに輝くボックスを取り付けます: 
api.updateEntityNodeMeshAttachment(
    playerId,
    "HeadMesh",
    "Box",
    { width: 0.3, height: 0.3, depth: 0.3, emissiveColor: [255, 215, 0] },
    [0, 0.5, 0],
)

nodeからメッシュを解きます: 
api.updateEntityNodeMeshAttachment(playerId, "ArmRightMesh", null)

役に立つ可能性のある参考文献タイプ。

MeshEntityOpts


type MeshEntityOpts = {
    Box: CommonMeshEntityOpts & {
        width: number
        height: number
        depth: number
        diffuseColor?: number[]
        emissiveColor?: number[]
        backFaceCulling?: boolean // デフォルト true
        texture?: string // ブロック名を指定できます。 すべてのブロックをラップ
        faceUV?: number[][]
        animateTexture?: boolean // True なら、`texture` はアニメーションブロック名(「Lava」、「Red Portal」など)と、そのフレームを介して Box サイクルでなければなりません。
    }
    BloxdBlock: CommonMeshEntityOpts & {
        blockName: BlockNameOrId
        size: number | [number, number, number]
    }
    Person: CommonMeshEntityOpts & {
        size?: number
        textures?: Partial<Cosmetics>
        pose?: PlayerPose
    }
    Leaderboard: LeaderboardMeshOpts
    ParticleEmitter: MeshParticleSystemOpts
}

CommonMeshEntityOpts


type CommonMeshEntityOpts = {
    hideDist?: number
    meshOffset?: number[]
    autoRotate?: boolean
    lineToEId?: EntityId // EntityIdはラインを使用して接続します
}

MeshEntityPhysicsOpts


type MeshEntityPhysicsOpts = {
    doPhysics: boolean
    onCollideTerrain?: () => void // カスタムコードをサポートしていない
    collidesEntities?: boolean
    collideBits?: number // このエンティティのビットマスクカテゴリ
    collideMask?: number // エンティティのこのエンティティのcollidesのbitmaskカテゴリ
    heightExpandAmt?: number // この量でhitboxの高さを拡張
    widthExpandAmt?: number // この量でhitboxの幅を広げる
}

MeshParticleSystemOpts


type MeshParticleSystemOpts = ParticleSystemOpts &
    CommonMeshEntityOpts & {
        height: number
        width: number
        depth: number
        emitRate: number
        /** 車両シートを含む、フォローされたライフフォームのビジュアルオフセットを含みます。 */
        followTargetMeshOffset?: boolean
        /**リングは周囲から放射状に放出します;幅/深さは直径、高さを厚さ置きます。 */
        emitterShape?: "box" | "ring"
        dir1?: number[]
        dir2?: number[]
    }

ParticleSystemOpts


type ParticleSystemOpts = {
    texture: string
    minLifeTime: number
    maxLifeTime: number
    minEmitPower: number
    maxEmitPower: number
    minSize: number
    maxSize: number
    gravity: number[]
    velocityGradients: VelocityGradient[]
    colorGradients: TimeColorGradient[] | RandomColorGradient[]
    blendMode: ParticleSystemBlendMode
}

TimeColorGradient


type TimeColorGradient = {
    timeFraction: number
    minColor: [number, number, number, number]
    maxColor?: [number, number, number, number]
}

RandomColorGradient


type RandomColorGradient = {
    color: [number, number, number]
}

VelocityGradient


type VelocityGradient = {
    timeFraction: number
    factor: number
    factor2: number
}

ParticleSystemBlendMode


enum ParticleSystemBlendMode {
    // 結果に影響を与えるアルファなしで宛先色に源色が加えられます
    OneOne = 0,
    // 粒子のアルファを使用して現在の色および粒子色を混ぜて下さい
    Standard = 1,
    // 粒子のアルファによって多彩される現在の色および粒子色を加えて下さい
    Add,
    // 粒子色の多重電流色
    Multiply,
    // 粒子色で現在の色を掛け、粒子のアルファによって多彩にされた現在の色および粒子色を加えて下さい
    MultiplyAdd,
}
