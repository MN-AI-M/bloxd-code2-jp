粒子


これらは粒子効果を取る機能に与えることができる文字列です texture inputとして:
arrow bubble critical_hit drift effect_5 fishingFishSilhouette generic_2 glint heart scary_face soul_0 square_particle z-particle
たとえば、effectのコードです。 
let [x, y, z] = thisPos
y += 1
api.playParticleEffect({
    dir1: [-1, -1, -1],
    dir2: [1, 1, 1],
    pos1: [x, y, z],
    pos2: [x + 1, y + 1, z + 1],
    texture: "bubble",
    minLifeTime: 0.2,
    maxLifeTime: 0.6,
    minEmitPower: 2,
    maxEmitPower: 2,
    minSize: 0.25,
    maxSize: 0.35,
    manualEmitCount: 20,
    gravity: [0, -10, 0],
    colorGradients: [
        {
            timeFraction: 0,
            minColor: [60, 60, 150, 1],
            maxColor: [200, 200, 255, 1],
        },
    ],
    velocityGradients: [
        {
            timeFraction: 0,
            factor: 1,
            factor2: 1,
        },
    ],
    blendMode: 1,
})

また、 presetId 定義済みのパーティクルエフェクトを使用する代わりに、エンジン内で使用するエフェクトを再現します。 ここでは、presetId を使用する例のコードです。 
let [x, y, z] = thisPos
y += 1
api.playParticleEffect({
    presetId: "aura",
    pos1: [x, y, z],
    pos2: [x + 1, y + 1, z + 1],
})
